# About this organization

This organization exists for testing purposes only. It is a development and
test fixture for CI/CD tooling: a realistic estate of repositories, in many
languages and with many different GitHub Actions workflows, used to exercise
software that reads, analyzes and governs CI/CD configuration.

Every repository here is a detached copy of an open-source project, imported
as a single commit from its default branch under that project's own licence,
which is kept in the copy. The source of each copy is named in its description
and in its one commit. None of them is the upstream project: do not report
issues or open pull requests here expecting them to reach the original
maintainers, and do not depend on anything in this organization.

Workflows may be edited, broken on purpose, or left outdated: that is what the
fixture is for.
